# Taking a Picture of the Quark-Gluon Plasma

A 7-minute chalkboard explainer (English narration) of the CMS measurement of
Bose-Einstein correlations and Lévy source parameters in PbPb collisions at 5.02 TeV,
written for undergraduate students.

- Video file: `levy_femtoscopy_chalkboard.mp4`
- Web page with player: `index.html` (served by GitHub Pages)

## Source

CMS Collaboration, "Two-particle Bose-Einstein correlations and their Lévy parameters
in PbPb collisions at √sNN = 5.02 TeV", Phys. Rev. C 109, 024914 (2024),
https://doi.org/10.1103/PhysRevC.109.024914

Figures from the paper are reproduced under the CC BY 4.0 licence.
This is an unofficial educational explainer, not a CMS Collaboration product.
The narration uses a synthetic voice.
